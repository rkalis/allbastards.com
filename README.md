# ALLGLICPIX.COM

ALLGLICPIX.COM is a website for browsing the entire GLICPIXXXVER002 collection. It uses infinite scrolling and lazy loading as well as the WebP image/animation format for performance enhancement. All settings are persisted in local storage. The website is built using React and TailwindCSS. The funky background was made by Berk (the creator of BASTARD GAN PUNKS / GLICPIXXX)!

## Running locally
```shell
git clone git@github.com:rkalis/allbastards.com.git
cd allbastards.com
git checkout allglicpix.com
yarn
yarn start
```
